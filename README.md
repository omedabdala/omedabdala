# Omed Abdala — Graphic Design Portfolio

A responsive personal portfolio created to present my graphic design work, professional experience and visual identity.

The portfolio focuses on a minimal black-and-white design and showcases projects across branding, print and digital media.

## About Me

I am **Omed Abdala**, a multidisciplinary graphic designer working across:

- Brand identity and logo design
- Posters and advertising materials
- Social media design
- Books and editorial layouts
- Signage and visual communication
- Print preparation and production
- Wide-format, flex and UV printing
- CNC routing
- Laser cutting and engraving
- Sign-making and visual fabrication

My experience with both design and production helps me create work that is visually strong, technically accurate and ready for real-world use.

## Portfolio Features

- Responsive design for desktop, tablet and mobile
- Dark and light themes
- Theme-specific project artwork
- Animated and responsive navigation
- Active navigation based on the current section
- Project filtering by category
- Fullscreen project viewer
- Image zooming and dragging
- Two-finger pinch zoom for touch devices
- Keyboard and mouse support
- Responsive project layouts
- Custom SVG logo and browser favicon
- Smooth and lightweight interactions

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive CSS layouts
- CSS custom properties
- Local Storage for theme preferences
- Pointer Events for touch and mouse controls
